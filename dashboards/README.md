## 💾 How to Download the Packaged Workbook (`.twbx`)

To explore the calculations, parameters, LOD expressions, and dashboard layout locally:

### Option 1: Direct Download from Tableau Public (Recommended)
1. Navigate to the **[Tableau Public Dashboard Link](https://public.tableau.com/app/profile/akash.yadav1833/viz/FoodOrderingBehaviourAndConsumerTrend/Dashboard1?publish=yes)**.
2. In the bottom-right footer of the dashboard view, locate and click the **Download** icon (📥).
3. Select **Tableau Workbook** from the options presented.
4. If prompted, confirm download of the current version. The `.twbx` file will download to your local drive.

### Option 2: Local Repository Copy
- You can place your local packaged workbook inside this directory as `Food_Ordering_Behaviour_and_Consumer_Trend.twbx`.
- *Note:* If the `.twbx` exceeds GitHub's 100MB file limit or contains proprietary data extracts, Git LFS (Large File Storage) should be used, or the Tableau Public link can serve as the primary distribution hub.
