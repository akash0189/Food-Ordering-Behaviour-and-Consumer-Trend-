# 🖼️ Dashboard Screenshots & Visual Assets

This directory stores visual assets and high-resolution screenshots of the **Food Ordering Behaviour and Consumer Trend** dashboard.

---

## 📸 Recommended Screenshots & File Naming Conventions

To ensure images render properly across GitHub's web interface and mobile app, use the following standardized filenames:

| File Name | Description | Placement in README |
|:---|:---|:---|
| `dashboard_overview.png` | Full-screen overview of the primary executive dashboard | Main Hero Preview |
| `peak_ordering_hours.png` | Deep-dive chart into hourly volume and peak ordering spikes | Key Analysis Section |
| `cuisine_preference_analysis.png` | Breakdown of order revenue and volume across cuisine categories | Deep Dive Section |
| `delivery_retention_kpis.png` | Delivery SLA performance, customer retention, and AOV metrics | Operational Metrics Section |

---

## 📋 Best Practices for High-Resolution Capture

1. **Resolution**:
   - Minimum: 1920 × 1080 px (16:9 aspect ratio) or 1600 × 900 px.
   - Format: **PNG** (preferred over JPEG to avoid text/chart artifact compression).
2. **Exporting Directly from Tableau Public**:
   - Open the [Tableau Public Dashboard](https://public.tableau.com/app/profile/akash.yadav1833/viz/FoodOrderingBehaviourAndConsumerTrend/Dashboard1?publish=yes).
   - In the toolbar at the bottom right, click **Download** -> **Image**.
   - Save the image directly as `dashboard_overview.png` inside this `images/` directory.
3. **Capture via Snipping Tool / Screenshot Utility**:
   - Set OS display scaling to 100% or 125% to prevent blurry fonts.
   - Capture only the dashboard canvas without browser address bars, bookmarks, or tabs.
   - Optimize file size using tools like TinyPNG if images exceed 5MB.
